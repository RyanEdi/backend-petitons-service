# Petitions Service

Servico de preview e geracao de PDF de peticoes.

## Scripts

- npm run dev
- npm run build
- npm run start

## Variaveis de ambiente

- PETITIONS_SERVICE_PORT (default 3336)
- FRONTEND_URL

## Publicar como novo repositorio

1. git init
2. git add .
3. git commit -m "init petitions-service"
4. git branch -M main
5. git remote add origin <URL_DO_REPO>
6. git push -u origin main
